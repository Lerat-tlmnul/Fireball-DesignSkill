# 🔥 FireBall Design v1.2

## Adapt to the Prompt

FireBall Design v1.2 is a major evolution of the skill.

This release makes the AI much better at understanding the actual intent behind a prompt, instead of repeating the same visual habits over and over again.

The core rule is now simple:

> **Every style choice must match the prompt.**

---

# 🧠 Prompt Adaptation

A new core principle has been added:

> **Adapt to the Prompt**

The AI must now analyze:

* the brand personality
* the target audience
* the product type
* the emotional goal
* the visual references
* the platform constraints
* the business objectives
* the desired level of creativity

References such as Apple, Stripe, Notion, and others are no longer default inspirations.

They are treated as constraints, not automatic templates.

---

# 🎯 New Workflow

FireBall Design v1.2 introduces a more intelligent workflow.

## Before

* Analysis
* Structure

## Now

* Analysis
* Intent Detection
* Blueprint
* Style Matching
* Execution

This creates a better design process and helps the AI produce interfaces that feel more intentional and less generic.

---

# 🎨 Style Adaptation

The AI now adapts the design style automatically based on the prompt.

Supported directions include:

* Professional
* Premium
* Futuristic
* Experimental
* Playful
* Corporate
* Artistic

The AI should no longer generate the same type of website every time.

Each prompt should lead to a different visual language.

---

# 📐 Visual Composition

A new complete section has been added for composition quality.

The AI now needs to think about:

* white space
* alignment
* balance
* rhythm
* Gestalt principles
* symmetry and asymmetry
* visual grouping

This improves structure, readability, and overall visual flow.

---

# 🧩 Component Engineering

FireBall Design v1.2 now includes a full component engineering system.

The AI must design each component with clear rules for:

* sizes
* states
* spacing
* radius
* shadows
* feedback

Covered components include:

* Buttons
* Inputs
* Cards
* Modals
* Sidebar
* Navbar
* Dropdown
* Tabs
* Badges
* Toasts
* Tables
* Empty states
* Error states

This helps generate more complete and production-ready interfaces.

---

# 🎛️ Design Tokens

A new design token section has been added.

The AI should now work with consistent tokens for:

* spacing
* radius
* shadow
* font
* transition
* surface
* primary
* secondary
* accent
* border
* elevation
* focus ring

This makes the system more coherent and easier to scale.

---

# 🎨 Colors

The color system has been upgraded.

## Before

* Avoid raw hex values

## Now

* Prefer perceptual color spaces
* Adapt colors to the requested style

A new color adaptation system has also been added.

Colors should now change depending on the prompt instead of staying visually identical across every project.

---

# ✍️ Typography

Typography must now match the prompt style.

Examples:

* Luxury
* Gaming
* Premium
* Playful

The AI should choose typography that supports the tone of the interface, not just the layout.

---

# 🎬 Motion

The motion section has been greatly expanded.

Animation should now adapt to the requested style:

* Premium
* Gaming
* Editorial
* Futuristic
* Playful

Motion is no longer just decoration.

It is part of the experience.

---

# 📱 Responsive Design

New responsive rules have been added for modern layouts.

The AI must now consider:

* Container Queries
* Fluid Typography
* Safe Areas
* Ultra Wide screens
* Small Screens

This improves adaptability across devices and screen sizes.

---

# 🧠 UX

A new UX principle has been added:

* Progressive Disclosure

The interface should reveal information gradually and avoid overwhelming the user.

---

# ⚡ Performance

FireBall Design v1.2 now includes a full performance section.

The AI must consider:

* LCP
* CLS
* INP
* Lazy Loading
* Responsive Images
* Font Loading
* GPU Animations

The goal is not just to make the interface beautiful, but fast and stable too.

---

# ✍️ UX Writing

A new UX writing section has been added.

The AI must improve the wording of:

* buttons
* placeholders
* error messages
* confirmations
* instructions

The interface should sound clear, helpful, and intentional.

---

# 📭 Empty States

Empty states are now mandatory.

The AI must always design a useful empty screen instead of leaving a blank or dead area.

Empty states should guide the user and keep the experience alive.

---

# ❌ Error States

A new error state system has been added.

The AI must handle:

* 404
* 500
* Offline
* Validation
* Retry
* Loading failures

Errors should feel designed, not forgotten.

---

# 📊 Data Visualization

Data visualization now has its own section.

The AI must follow good practices when designing:

* charts
* graphs
* metrics
* dashboards
* data cards

The goal is to improve clarity, hierarchy, and readability.

---

# 🔍 Updated Critique System

The critique system now checks more than accessibility and hierarchy.

New criteria include:

* Style Matching
* Performance

The AI must evaluate whether the design truly fits the prompt and whether the implementation respects modern performance standards.

---

# 🎨 Creativity Scaling

A new creativity scaling system has been added.

The AI must adapt its level of creativity based on the request.

It should not produce generic interfaces by default.

The design should feel more original when the prompt asks for originality, and more structured when the prompt asks for discipline.

---

# 💻 Code Standards

Code standards now include:

* Prompt-aware styling
* Consistent tokens

This keeps the generated code aligned with the design intent from start to finish.

---

# 🌬️ Tailwind

A new Tailwind rule has been added:

> **Tailwind should accelerate the system, not replace it.**

The framework must support the design system, not become a shortcut that destroys it.

---

# ✅ Final Validation

Before generation, FireBall Design now runs a stronger validation loop.

The AI must verify that:

* the design matches the prompt
* the result is original
* the interface is accessible
* the AI is not repeating its habits
* the result does not look like a generic AI website

This final check helps keep the output aligned with the project vision.

---

# 🏛️ Philosophy

FireBall Design v1.2 is built on one core idea:

> **Every style choice matches the prompt.**

That means the AI should stop relying on default visual patterns and start adapting to the real intention behind each request.
