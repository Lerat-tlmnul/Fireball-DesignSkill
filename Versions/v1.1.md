# 🔥 FireBall Design v1.1

## Release Notes

FireBall Design v1.1 introduces stricter design engineering rules to improve the quality, consistency, performance, and accessibility of AI-generated interfaces.

This update focuses on making AI-generated code closer to professional production standards.

---

# 🚀 What's New

## 🎨 Tailwind Discipline

A strict Tailwind CSS discipline has been introduced.

AI-generated code must no longer use arbitrary values when a design system value already exists.

Examples of forbidden patterns:

~~~css
mt-[17px]
p-[23px]
text-[14.5px]
~~~

The AI must adapt to the design system instead of creating random values.

The goal:

- Better consistency
- More reusable components
- Cleaner code
- Stronger design systems

---

## 🖼 Image & Media Handling

FireBall Design v1.1 improves image management.

All images must now include explicit `width` and `height` attributes.

Example:

~~~html
<img 
  src="image.webp"
  width="1200"
  height="630"
  alt="Description"
/>
~~~

This prevents unexpected layout movement and targets:

**CLS (Cumulative Layout Shift): 0**

The AI must also use:

- Correct image ratios
- Suitable placeholders
- Better media loading strategies

---

## 🌙 Dark Mode by Default

Dark mode is now built into every generated interface.

It is no longer an optional feature.

Generated code must include:

- Dark mode variables
- Theme-ready colors
- Proper contrast
- Dark-compatible components

The interface should support dark environments from the beginning.

---

## 🌍 Internationalization (RTL Support)

FireBall Design v1.1 adds native support for right-to-left languages.

The AI must use CSS logical properties instead of fixed directions.

Example:

Before:

~~~css
margin-left: 20px;
~~~

After:

~~~css
margin-inline-start: 20px;
~~~

This makes interfaces compatible with languages such as:

- Arabic
- Hebrew
- Persian

without requiring major modifications.

---

# 🔍 Updated Code Critique Framework

The FireBall Design analysis system has been improved.

It can now detect:

## Tailwind Issues

- Arbitrary Tailwind values
- Poor spacing consistency
- Design system violations

## Layout Issues

- Missing image dimensions
- Potential layout shifts
- Responsive problems

## Design Issues

- Inconsistent UI patterns
- Weak component structure
- Generic AI-generated designs
