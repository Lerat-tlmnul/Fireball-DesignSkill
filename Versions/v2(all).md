# UI Design Engineering Skills - Version Comparison

## Overview

This document presents the evolution of UI Design Engineering skills across four versions. The three new skills represent a progressive refinement of the discipline, moving from a comprehensive foundation to specialized tiers for different use cases.

---

## Skill Versions at a Glance

| Aspect | v1_2 (Legacy) | v2 ECO | v2 Standard | v2 ULTRA |
|--------|---------------|--------|-------------|----------|
| **Token Cost** | High | Minimal | Standard | Maximum |
| **Depth** | Comprehensive | Concise | Complete | Absolute |
| **Best For** | General UI design | Quick, focused execution | Professional projects | Maximum quality output |
| **Core Philosophy** | Engineering discipline | Token-efficient engineering | Production standard | Complete operating system |
| **Anti-Default** | Present | Blocking | Blocking | Blocking |
| **Workflow Phases** | 5 phases | 4 steps | 5 phases | 5 phases |
| **Adaptation Engine** | Basic | Structured table | Complete | Complete |
| **Token System** | Present | Streamlined | Production kit | ULTRA kit |

---

## v2 ECO - Economy Version

### Purpose
The economy version strips the skill to its essential core. It maintains all critical principles while minimizing token usage. Best for quick executions where the designer already understands the fundamentals.

### What's Included
- **Anti-Default Rule** – Blocking enforcement against generic patterns
- **4-Step Workflow** – Streamlined process: Context > Intent > Structure > System
- **Adaptation Engine** – Quick-reference table for 7 intent types with specific parameters
- **Token System** – Core tokens: spacing, radius, shadows, transitions
- **6 Execution Laws** – Content First, Hierarchy, A11y, Responsive, Real Product, Perf
- **Final Checklist** – 8-point validation

### What's Omitted (vs Standard)
- Deep cognitive psychology explanations
- Extended component specifications
- Complete color system engineering
- Detailed performance engineering
- Comprehensive critique frameworks
- Extended code standards

### Example Use Case
> "Design a professional dashboard for a fintech product" → Quick, focused execution with minimum overhead.

---

## v2 Standard - Production Version

### Purpose
The full production standard. Treats UI as engineering discipline with complete coverage of all critical areas. Best for professional projects requiring comprehensive design systems.

### What's Included (Beyond ECO)
- **Extended Anti-Default** – Reference adaptation principles (Apple, Stripe, Linear, Notion, Gaming, Luxury, Cyberpunk, Brutalist)
- **5-Phase Workflow** – Full process: Context Analysis > Intent Detection > Structural Blueprint > Style Matching > Production Engineering
- **Complete Design System**:
  - 8pt spacing engineering with rules
  - Typography engineering (modular scale, readability)
  - Color engineering (60/30/10, OKLCH, dark mode)
  - Motion design (timing, easing, adaptation)
  - Layout architecture (Gestalt, composition)
- **Component Engineering** – Production specs for buttons, inputs, cards, tables, navigation, feedback
- **Design Tokens** – Complete production kit
- **Cognitive Load** – Hick's Law, Miller's Law, Progressive Disclosure
- **Accessibility** – Non-negotiable standards
- **Performance Engineering** – Core Web Vitals, LCP, CLS, INP
- **Content First** – UX Writing, empty states, error states
- **Critique Frameworks** – Self-review system
- **Final Validation** – 10-point blocking checklist

### What's Omitted (vs ULTRA)
- Maximum depth in each category
- Extended token system (ULTRA has 16 spacing values vs 9)
- Complete component specification tables
- Extended code standards (React, Tailwind details)
- 16-point validation (vs 10-point)
- "Complete OS" level philosophy

---

## v2 ULTRA - Maximum Quality Version

### Purpose
The absolute complete operating system for UI Design Engineering. Token cost irrelevant. Maximum depth, maximum quality. Best for critical projects where every detail matters.

### What's Included (Beyond Standard)
- **Complete Philosophy** – First principles, laws, and "what is UI Engineering" framework
- **Extended Anti-Default** – "No Prototype Mindset" added
- **Deep Phase 1 Analysis**:
  - User Analysis (age, tech literacy, context, knowledge level, mental models, jobs to be done)
  - Platform Analysis (Web, Mobile Web, iOS, Android, Desktop, Tablet)
  - Product Analysis (category, main objective, business model, conversion goal, north star metric)
  - Experience Analysis (cognitive friction points, required emotional response, creativity level)
- **Extended Intent Detection** – 10+ intent types with detailed descriptions
- **Complete Design System** – Every section deeply expanded:
  - **Spacing**: 16 values (vs 9), 4px exceptions, spatial rhythm rules
  - **Typography**: Full modular scale, readability rules, adaptation per intent
  - **Color**: OKLCH/HSL preference, 60/30/10, dark mode engineering
  - **Motion**: Complete timing system, easing rules, adaptation per intent
  - **Layout**: Gestalt & Composition (Proximity, Similarity, Continuity, Closure, Figure‑Ground)
  - **Cognitive Load**: Hick's Law, Miller's Law, Progressive Disclosure with detailed explanations
  - **Data Visualization**: Chart principles, rules, type selection
- **Complete Component Engineering**:
  - Button Engineering (primary/secondary/tertiary, states, sizes)
  - Inputs & Forms (anatomy, states, accessibility)
  - Cards, Tables, Navigation (consistent design)
  - Feedback Components (badges, toasts, modals, empty states, loading states, error states)
- **Extended Token System**:
  - 16 spacing values
  - 9 radius values
  - Complete shadow system
  - Full typography tokens
  - Complete color system (OKLCH)
  - Comprehensive motion tokens
  - Z‑index system
  - Component‑specific tokens
  - Dark mode complete
- **Complete Code Standards**:
  - HTML standards
  - CSS standards
  - Tailwind rules
  - React standards
- **Extended Critique Frameworks**:
  - Cognitive Load Review
  - Visual Hierarchy Review
  - Spatial Mathematics Review
  - Accessibility Review
  - Style Matching Review
  - Performance Review
  - Content Review
- **Creativity Scaling** – Detailed per intent
- **16‑Point Blocking Checklist** – Extended validation
- **Design Philosophy** – Closing law and complete vision

## Quick Selection Guide

### Choose v2 ECO when:
- You need quick, focused execution
- Token usage must be minimal
- You already understand UI engineering fundamentals
- The project is straightforward

### Choose v2 Standard when:
- You need comprehensive coverage
- The project requires professional quality
- You want complete design systems
- You need validation frameworks

### Choose v2 ULTRA when:
- Maximum quality is required
- Token cost is not a constraint
- Every detail matters
- You need complete code standards
- The project is critical

### When to keep using v1_2:
- You're already familiar with it
- You don't need the new features
- Token budget is medium but not minimal
- You prefer the original structure

## Summary

The v2 series represents a significant evolution in UI Design Engineering:

1. **ECO** provides the essential core for quick execution  
2. **Standard** delivers complete production capability  
3. **ULTRA** offers maximum depth for critical projects  

All versions maintain the core philosophy of treating UI as engineering, not taste, while adapting to different use cases and constraints.
